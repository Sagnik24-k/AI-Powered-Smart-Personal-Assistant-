# 🧠 AI-Powered Smart Personal Assistant  
A Natural Language Powered Assistant built in Jupyter Notebook

## 📌 Overview  
This project is an *AI-powered Smart Personal Assistant* capable of understanding *natural language commands* and performing various useful tasks. Built in *Python* using *Jupyter Notebook*, it demonstrates how NLP, automation logic, and API integrations can work together to create an intelligent personal assistant.

The assistant can:  
- 💬 Answer general questions  
- ⏰ Set reminders  
- 🌦 Provide weather updates  
- 🗂 Manage schedules  
- 📚 Fetch information  
- ⚙ Execute custom commands  

---

## 🚀 Features

### 🧠 Natural Language Understanding  
Interprets user queries and commands using NLP techniques.

### 📅 Task & Schedule Management  
Allows users to create, track, and manage tasks or reminders.

### 🌤 Weather Information  
Retrieves real-time weather details for any city using integrated APIs.

### ❓ Question Answering  
Provides intelligent responses to user questions based on built-in logic or model inference.

### 🛠 Built Entirely in Jupyter Notebook  
Great for learning, experimentation, and showcasing step-by-step development.
